packJPG package - table of contents
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~


Source files
~~~~~~~~~~~~

All files needed to compile packJPG as an executable or as a library are 
included in the 'source' subdirectory': 

- 'Makefile' (universal makefile)
- 'aricoder.cpp' (arithmetic coder source file)
- 'aricoder.h' (arithmetic coder header file)
- 'bitops.cpp' (bitwise stream and file I/O source file)
- 'bitops.h' (bitwise stream and file I/O header file)
- 'cli_main.cpp' (command-line interface and main entry point)
- 'codec_context.h' (reentrant codec state and RAII working buffers)
- 'codec_pipeline.cpp' (compression/decompression pipeline driver)
- 'codec_pipeline.h' (pipeline driver and reentrant C++ memory API header)
- 'dct8x8.h' (discrete cosine transform tables header file)
- 'dev_tools.cpp' (optional developer/debugging dump routines)
- 'dev_tools.h' (developer/debugging dump routines header)
- 'jpeg_codec.cpp' (JPEG marker parser and Huffman decode/recode module)
- 'jpeg_codec.h' (JPEG codec module header)
- 'packjpg_api.cpp' (C/DLL library API implementation)
- 'packjpglib.h' (packJPG static library header file)
- 'path_utils.h' (cross-platform filesystem path helpers)
- 'pjg_codec.cpp' (PJG predictors, zero-distribution, and context coding module)
- 'pjg_codec.h' (PJG codec module header)
- 'pjpgtbl.h' (helper tables header file)

These files are included as well, but are not necessarily needed for 
compiling packJPG: 

- 'packjpg.spec' (RPM spec file, provided by Bryan Stillwell)
- 'Makefile_osx' (macOS compatibility Makefile wrapper)
- 'packjpgdll.h' (packJPG shared library header file)
- 'file_icon.ico' (suggested .pjg icon in .ico format)
- 'app_icon.ico' (application icon in .ico format)
- 'icons.rc' (Windows resource script for application and .pjg icons)


Documentation
~~~~~~~~~~~~~

The packJPG source code is well commented. Additionally, 'Readme.txt' and
'LICENSE' are provided in the root directory, and these files are included
in the 'docs' subdirectory:

- 'developer.txt' (information about developer functions)
- 'sample_images.zip' (sample images, referenced in 'developer.txt')
- 'howtocompile.txt' (compile instructions)
- 'versionnumbering.txt' (version numbering guideline)
- 'lgpl-3.0.txt' (GNU Lesser General Public License v3.0)
- 'contents.txt' (the file you are currently reading)


*NOT* included
~~~~~~~~~~~~~~

There's no further documentation on the packJPG algorithms - all 
documentation is included within the source code.
